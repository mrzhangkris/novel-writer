# story-deslop：网文去AI味

> 只改「怎么说」（句式/书面腔/节奏工整/修饰词），不改「说什么」（剧情/人设/设定/时间线）。机械病句（语序/残缺/搭配）走 story-polish，别混改。

## 核心原则

1. **改味优先，别当改错**：AI 味是风格问题（过度圆滑、工整、解释充分），不是语法错误。目标是保留剧情功能，增加口语、停顿、跳跃和具体动作。
2. **改最少，效果最大**：能改一个词不改一句，能删一句不重写一段。人名/地名/数字/专有名词优先保留。
3. **保留创作意图**：不新增原文没有的情节、设定、关系、时间线；原文逻辑问题不归本支线管。
4. **不过度去AI味**：不整段删除正文；删除前确认不丢伏笔/钩子/角色特征/情节推进/因果锚点；删除比例上限轻度 ≤15%、中度 ≤25%、重度 ≤35%，超限标 `[需复核]` 不计入。改后若只剩最短句、每个动作都带「了一下」，是电报体——把非峰值句恢复成自然白话。
5. **有功能的语气保留**：质问的 `？`、爆发的少量 `！` 保留；犹豫/打断/拖长用动作、短句、换行处理。正文不保留 `……` / `——` 和无功能标点堆砌。
6. **直白保留**（安全说明/法规/医疗等必须字面准确的内容）：不改，报告标 `[直白保留]`。

## 自然文本 vs AI 味

| 维度 | 自然文本 | AI 味 |
|------|----------|--------|
| 段落长度 | 随 beat 长短不一 | 通篇均匀 |
| 情绪表达 | 动作展示（"手在抖"） | 直接告诉（"很紧张"） |
| 对话标签 | 低频、动作引出 | 每句"说道/笑道" |
| 比喻 | 生活化 | 文学化（"如寒冰般"） |
| 语气词 | "嘤""嘶""行吧" | 几乎没有 |
| 省略 | 大量省略读者脑补 | 面面俱到 |
| 排比 | 偶尔 1-2 个 | 连续 3-5 个 |
| 结尾 | 动作/对话收尾 | 总结/升华收尾 |

## 检测流程

### Phase 1：AI 味扫描

文件模式先跑检测器（只报告不改写）：

```
node {SKILL_DIR}/skills/branch/story-deslop/scripts/check-ai-patterns.js --check <文件...>
```

- 项目根 `.deslop-whitelist`（一行一词）定义豁免词（世界观术语/绰号），加 `--whitelist .deslop-whitelist`；`.deslop-extra-words` 新增本项目特有 AI 腔词，加 `--extra-words`。两个参数只在 deslop 支线手动复扫时带；主线 checks.py deai 闸门保持最严口径不带。
- 完整类别、例外与修法见 `references/anti-ai-writing.md`。

### Phase 2：诊断与分级

六项客观指标，**取最高档**；无重度时中度 ≥3 项按中度，否则轻度。量化与主观冲突以量化为准（只允许 ≤1 档主观下调并给书面理由，不许上调）：

| 指标 | 轻度 | 中度 | 重度 |
|------|------|------|------|
| 禁用词密度（次/千字） | ≤5 | 6-15 | >15 |
| 连续排比段数 | ≤2 | 3-4 | ≥5 |
| 心理词占比 | ≤10% | 10-25% | >25% |
| 对话标签密度 | ≤30% | 30-50% | >50% |
| 平均段落句数 | ≤3 | 3-5 | >5 |
| 重复描写密度（处/千字） | ≤1 | 2-3 | ≥4 |

开篇/高潮/收束出现 1 次重复描写加一档。题材差异酌情放宽（如古风对话标签天然偏高）。

| 程度 | 处理策略 |
|------|----------|
| 轻度 | Gate A + B |
| 中度 | Gate A + B + C + D + G |
| 重度 | 完整 7 Gate + 重点段落重写 |

### Phase 3：逐项清除

**执行方式**：文件模式默认 spawn 子代理执行 Gate（全文重写是重上下文工作），prompt 必须含：项目目录、正文文件路径、AI 味等级、Gate 范围、删除优先原则、两个 references 路径；子代理只改指定文件。一段以内的短片段才 inline。

**删除优先判断（先于各 Gate）**：每条被标记项先判能否删除——删掉后不丢伏笔/钩子/角色特征/情节推进/必要转折就直接删，不进 Gate；丢任意一项才进 Gate 改写。

#### Gate A：禁用词替换

加载 `references/banned-words.md` 逐项检查替换。

#### Gate B：句式去套路

| 句式 | 修法 |
|------|------|
| 否定铺垫接肯定翻转（不是A，而是B） | **最毒**。直接写后项，或改动作/细节 |
| "，带着…" / "声音不大，却带着…" | 拆独立短句或直接写特征 |
| "他/她知道…" | 用行为展示认知 |
| 陈词滥调/万能比喻 | 白描优先；确需比喻只留生活化、角色化的 |
| "仿佛/犹如/宛若" | 口语化或白描 |
| 对话标签公式化 | 普通"说"可保留；高频时用动作/上下文替代 |
| "不容置疑/显而易见" | 用具体事实说话 |

修饰词清扫：物品/人物前多余的形容词、定语、副词，删除后不影响阅读才删（"白色的药片"→"药片"；"多年的衣服"→"旧衣服"保留含义）。一次只用一个形容词。

#### Gate C：心理描写外化

- "他很紧张"→"他的手在抖"；"她很愤怒"→"她一把掀翻了桌子"
- 重复语义四类只留一个：形容词重复（"兴高采烈地笑着跑"→"笑着跑"）、近义词重复（"非常重要的关键问题"→"关键问题"）、含义重复（"我好饿，肚子咕咕叫"→"我好饿"）、上下文物品重复（第二次起只写"药片"不写全称）
- 相邻段重复描写合并，保留最推动情绪的细节；动作拆成"概述→感知→身体反应"的改成同一段连续画面

#### Gate D：节奏调整

- 打断连续排比（保留 1-2 个）；段落长短交错
- 只拆臃肿修饰/堆叠比喻/抽象总结的长句，**不把正常逗号长句拆成短句串**
- 标点跟语气走：保留有功能的 `？`/少量 `！`；`……`/`——` 改成动作、短句、换行，删随机堆砌

#### Gate E：对话去腔调

- 加口语词（"嗯""哦""行吧"）；允许答非所问；用动作穿插对话
- 删解释性对话（角色不会把动机说清楚）
- 台词同样过 Gate B 的工整否定检查，有明确人物/任务功能才保留
- 口误/停顿/粗话服务人物身份，不当"真人感"装饰批量添加；不把对话末尾全改句号

#### Gate F：结尾去升华

删总结性语句（"他知道…""这一刻…"基本可删）；用动作/场景收尾，不用感慨收尾。

#### Gate G：去解释腔/上帝感/安排感

最难察觉的一类——叙述者跳出来解释、剧透、定性，读者闻到"作者在场"：

- 删解释因果：「之所以…是因为」「原来…」「这意味着」——因果让读者自己拼
- 删上帝剧透：「她不知道的是」「殊不知」「多年以后」「仿佛预示着」
- 删替读者定性：「演得真好」「他就是这样薄情」——证据留给读者
- 删的是**非故事性的作者旁白**，不是情节；删完变薄靠动作/对话补，不补解说

### Phase 4：确定性收尾（文件模式）

先句式/段落复扫，再机械标点兜底：

```
node {SKILL_DIR}/skills/branch/story-deslop/scripts/check-ai-patterns.js --check --fail-on=blocking <文件...>
node {SKILL_DIR}/skills/branch/story-deslop/scripts/check-degeneration.js --check <文件...>
node {SKILL_DIR}/skills/branch/story-deslop/scripts/normalize-punctuation.js <文件...>
```

- `check-ai-patterns.js`：blocking 类别优先改正文并复扫；advisory 通读判断，功能性写法标 `[需复核]`
- `check-degeneration.js`：模型退化信号（复读/打转/截断/占位符/工程词泄漏）。blocking 是退化，去AI味改不掉，回炉重新生成该段；advisory 只提示
- `normalize-punctuation.js`：机械清除残留 `……`/`——`/`--`/独立 `---`；不动引号风格（知乎盐言短篇可保留 `「」`）

### Phase 5：输出报告

```
## 去AI味润色报告
### 字数：原文 N0 → 修订后 N1（净变化 ±X%，是否在 tier 上限内）
### 修改统计：按 Gate 分桶计数
### 前后对比：≤30 处全列；超过只列前 10 + 末 5 + 分桶计数
### 润色后全文：文件模式只回 ≤200 字代表片段（全文已落盘）；文本模式（交互贴入）才输出全文
```

**收敛终止**：同一段连续两轮无新改动 → 停；全文上限 3 轮，第 3 轮仍有 ≥10 处改动 → 标 `[需复核]` 移交人工。

## 五档强度

| 档 | 适用 | 做法 |
|---|---|---|
| 1 轻修 | 单点 AI 味 | 定点改词 |
| 2 中修 | 段落级 3-5 处 | Pass 1+2，句序微调 |
| 3 重修 | 全文多处 | 完整 7 Gate + 重点段重写 |
| 4 重写 | 段落功能保留的全句重写 | 句句重写，剧情功能/伏笔/钩子不动 |
| 5 风格变换 | 腔调不对（文风锚要求冷峻写成甜宠） | 按 style-anchor 换叙事腔调重写 |

判别：只改词=1，动句序=3，换腔调=5，句句重写=4。

## 使用场景

| 场景 | 操作 |
|------|------|
| 贴文字说"太AI了" | 完整检测 + 润色 |
| "帮我润色" | 先检测再润色 |
| "检查有没有AI味" / "只检测不要改" | 只扫描+分级，输出问题标记表，不改原文不写文件 |
