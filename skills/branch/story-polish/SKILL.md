# story-polish：文句通顺度修订

写出来的句子「读着不通」，是基础质量问题。本支线用子代理逐句扫描正文，挑出真病句并给出改写，按清单逐条修。

## 核心原则

1. **只挑真病句**：读两遍仍不顺、且能说出具体问题（语序/残缺/搭配/指代/标点）才挑；「读着怪但说不清」不挑。
2. **只改文句不动剧情**：改写不改动情节、设定、伏笔、人物关系；单句字数变化 ±20% 内。
3. **尊重网文修辞**（以下不算病句，禁止挑）：
   - 对话拆行（一句拆多行）、短句排比、名词短语镜头流（「灰墙，木窗，门脸……」）；
   - 「的」字多但读着顺的句子；
   - 人物口头禅、地方口语、仿档案/卷宗体（「周淑芬，四十六，开杂货店」）。
4. **改最少**：能改一个词不改一句，能调语序不重写。
5. **沉淀模式**：命中清单外的**新**病句模式（这次现发现的定式错误）→ 先登记到 `{SKILL_DIR}/references/issue-patterns.md`（按文件内格式：现象 + 正则建议），再照常改写；checks.py 的检测正则会随该登记本同步补强。

## 执行方式

1. 对目标章 spawn 子代理（独立上下文，防止带着作者记忆放水），prompt 见下节协议；子代理读 `chapters/chapter-NNN/draft.md` 全文。
2. 子代理输出问题清单（最多 15 句，按读感最差优先），每句一行：
   ```
   原文「…」→ 改写「…」｜问题类型：语序/残缺/搭配/指代/标点
   ```
3. AI 逐条审：把采纳项写成清单文件（每行 `原文「…」→ 改写「…」`，可在段首用 `# 第N章` 标注章节；不标则跨章搜唯一命中），批量替换走脚本（确定性动作，不要逐句 edit）：

```
python3 {SKILL_DIR}/scripts/polish_apply.py --project {书目录} --input 清单.txt --dry-run   # 先预览命中
python3 {SKILL_DIR}/scripts/polish_apply.py --project {书目录} --input 清单.txt             # 确认后落盘
# 未命中的条目（原句已改过/出现多次）打印出来，逐条人工处理
```
拿不准或改后变味的跳过并在 review.md 注明「未采纳：理由」。
4. 改完过闸门（最小可执行命令，不得用 advance draft 推进状态机）：
   - 字数：`python3 {SKILL_DIR}/scripts/checks.py wordcount chapters/chapter-NNN/draft.md --platform {平台} --type {类型}`
   - 去AI味：`node {SKILL_DIR}/skills/branch/story-deslop/scripts/check-ai-patterns.js --check --fail-on=blocking chapters/chapter-NNN/draft.md`
5. 结果记入该章 review.md：`## 通顺度修订（story-polish）`，列出采纳/未采纳数。

## 子代理协议（逐字传达）

```
你是文句编辑。任务：逐句通读正文，只挑「不通顺」的句子。

扫描优先级（先按与写作时同一套清单扫，再补通用）：
1. 本章 spec「语病避雷」节逐条对照（写作时写手防的就是这份清单，命中概率最高）；
2. {SKILL_DIR}/references/issue-patterns.md 的已登记模式；
3. 通用五类兜底。

判定标准（必须同时满足）：
1. 以读者身份连读两遍，这句仍让你停顿或别扭；
2. 能说出具体问题：语序别扭 / 成分残缺（缺主语缺宾语且补不回来）/ 搭配不当 / 指代悬空 / 标点断错造成歧义；
3. 你能给出改写，且改写不改动情节与设定、字数变化在 ±20% 内。

排除项（禁止挑）：
- 对话拆行、短句排比、名词短语镜头流（网文节奏，有意为之）；
- 「的」字多但读着顺的句子；人物口头禅、方言；仿档案/卷宗体；
- 文风形态（短段/句长分布）——那是 style-anchor 与写手档案管的，不归你。

输出格式，每句一行：
原文「…」→ 改写「…」｜问题类型：语序/残缺/搭配/指代/标点

最多挑 15 句，按「读感最差」优先。**开头 500 字逐句精读、优先挑**（黄金三章留存关键，开头病句致命度最高）。找不到就输出「本章无不通顺句」，不要硬挑。
```

## 触发与范围

- 单章：`/story-polish` + 章号；或 novel-revise 环节冷读打回时顺带跑。
- 全本：按章跑，每章一轮；改完全本重新导出成书。
- 本支线只处理文句通顺度；AI 味（微动作复读/电报体/否定短句起手/总结腔）走 story-deslop（按写手档案盯防项清），剧情问题走 novel-revise。
- 发现 AI 味模式不属本支线职责——在 review.md 注明「转 deslop：<模式>」即可，不越权改写。
