# story-long-scan：网文扫榜（长篇 + 短故事）

> 核心信念：**单本排名只是线索，跨样本重复模式才是信号。** 排行榜证明样本存在；需求强度靠多榜单、多作品、近期数据验证。扫榜目的是找到「你能写」的爆款题材——每个方向都要过可行性判断（素材储备/题材边界/篇幅承载），不按热度直接下结论。

## 扫榜流程

### Phase 1：确认形态和平台

先问「长篇还是短故事？」，再问「哪个平台？有没有关注的题材方向？」：

| 形态 | 平台 | 扫什么 |
|---|---|---|
| 长篇 | 起点/番茄/晋江/七猫 | 新书榜/月票榜/畅销榜 |
| 短故事 | 知乎盐选/番茄短故事 | 盐选热门、短故事榜 |

用户有方向 → 深度扫该方向；没方向 → 全榜概览找趋势；想跨平台 → 对比分析。

### Phase 2：确定数据来源

| 优先级 | 模式 | 何时用 |
|--------|------|--------|
| 1 | **search 技能**多引擎搜索（默认） | 联网环境 |
| 2 | 用户提供截图/文字/文件 | 用户已有数据 |
| 3 | 内置知识 `references/genre-trends.md` | 无法联网，产出标注「候选假设，需复扫」 |

搜索用具体问题不搜泛泛主题；番茄必须用「番茄免费小说」全称（防歧义成植物），如「番茄免费小说 2026 热门题材排行」「起点 玄幻 新书榜 近期」。

可选脚本采集（替代纯搜索转述）：四平台 SSR 点结构化样本——番茄 requests+`__INITIAL_STATE__`、起点 m.qidian.com、七猫 Nuxt `__NUXT__`、飞卢 HTML，字段 `|书名|题材|作者|字数|在读数|`。采集失败回退搜索，不阻塞。

### Phase 3：数据分析

**晋江硬性要求**：样本必须逐本带核心指标（收藏/在读/评分），只有书名列表视为不合格。

按平台看核心维度，再对全部数据提取通用七项：题材分布 / 新题材信号 / 经典题材走势 / 字数与更新 / 书名模式 / 开头卖点 / 新元素对比（与上期或同类榜对比）。

**内置知识模式降级**：无实时榜单时，「榜上数量/样本数」写「无可数样本」、「新元素对比」写「无上期基线，跳过」、「趋势」列写「？」——不得编造具体数字。

| 平台 | 核心指标 | 看什么 |
|---|---|---|
| 起点 | 追读率、月票 | 月票榜（付费认可）、畅销榜（最硬核）、三江推荐（编辑力推）、新书榜（新题材信号） |
| 番茄 | 在读数 | 阅读榜（流量）、新书榜、标签热词（简介【】内组合如「种田+慢热+西幻」） |
| 七猫 | 热度 | 大热榜、新书榜（新风口）、完结榜（长尾） |
| 晋江 | 收藏、营养液 | 金榜、季度榜、红字/黑字（积分与负面） |

### Phase 4：输出扫榜报告

```
# 网文扫榜报告：{平台}（长篇/短故事）
## 市场概况（扫榜时间 + 一句话核心发现）
## 题材热度排行（|排名|题材|榜上数量|趋势|代表作|）
## 新题材信号 / 经典题材动态（各附依据）
## 新元素提取（新人物设定 / 新开篇切入点 / 新桥段，各附代表作）
## 关键数据洞察（字数区间 / 更新频率 / 书名特征 / 标签热词）
## 值得关注的方向（2-3 个，附为什么值得 + 可行性评估）
## 一句话总结
```

### Phase 5：topic-decision

产出 `{outdir}/topic-decision.md`：2-3 个推荐选题，每个按四步（能爆的原因 → 市场验证 → 差异化定位 → 可行性+失败风险+验证动作）。完整方法见 `references/topic-decision.md`。

每个选题附一行「对标拆书候选」——从榜单挑 1 本最接近的爆款，标注「建议拆：《书名》（理由）」，供 novel-init 拆书环节直接取用。

**硬规则**：
- 同方向可数样本 <15（小平台 <10）⇒ 可行性不许给「高」，强制降「中」+ 写明先验证；内置知识模式一律「中」。样本数必须数出来写进报告
- 不输出项目素材无法支撑的题材；不忽略平台调性差异（起点男频和晋江女频审美完全不同）

## 平台特性速查

| 平台 | 调性 | 主力读者 | 适合类型 |
|------|------|----------|----------|
| 起点 | 男频硬核爽文，订阅制 | 18-35 男性 | 玄幻、都市、科幻、游戏 |
| 番茄 | 下沉免费，快节奏 | 大众读者 | 脑洞、强爽感 |
| 晋江 | 女频精品 | 16-30 女性 | 言情、纯爱、衍生 |
| 七猫 | 下沉免费 | 大众读者 | 快节奏爽文 |
| 刺猬猫 | 二次元轻小说 | 15-25 ACG | 同人、二次元 |

## 流程衔接

找到方向 → story-long-analyze 拆书对标；直接开写 → novel-writer 主流程。按需加载：`references/topic-decision.md`、`references/publishing-guide.md`（平台适配/简介设计）。
