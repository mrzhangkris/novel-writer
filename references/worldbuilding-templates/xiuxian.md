## 力量 / 能力体系

- 能力来源：灵根——天地灵气经灵根炼化为法力；灵根分五行杂灵 / 单纯灵 / 天灵根，资质决定修炼速度与瓶颈数
- 分级：炼气 → 筑基 → 金丹 → 元婴 → 化神，共五大境界，每层分初期 / 中期 / 后期 / 圆满；小境界靠灵气积累，大境界需突破契机 + 心魔劫
- 上限与代价：凡界灵气浓度上限封顶化神，再往上需飞升灵界（本书不写飞升后）；强行催动超出两境的力量反噬经脉；每次破境需灵石与破境丹，失败轻则修为跌落，重则走火入魔

## 世界硬性法则

- 亡者不可复活：魂飞魄散即永灭，夺舍重生只保记忆不保原人——死了就是死了
- 境界压制刚性存在：越一大境界可借法宝 / 阵法周旋，越两大境界正面必败，无例外
- 修为不可速赠：灌顶 / 传功至多提升一个小境界，且有上限次数；不存在「一夜成仙」的外挂通道

## 时代与背景

- 时代设定：架空古典仙侠，皇权与宗门共治——凡人王朝管俗世，修士宗门占灵脉山川
- 关键背景：三百年前「灵潮枯竭」令北境灵脉尽断，宗门南迁，北境沦为散修与魔修争食之地；主角从北境起步

## 灵石经济

| 货币 / 资源 | 换算 | 典型用途 |
|---|---|---|
| 下品灵石 | 1 中品 = 100 下品 | 日常修炼、低阶法器 |
| 中品灵石 | 1 上品 = 100 中品 | 破境辅助、租用洞府 |
| 上品灵石 | 极稀有，宗门级储备 | 金丹以上破境、拍卖会硬通货 |
| 灵草 / 妖丹 | 按年份与品阶浮动 | 炼丹原料，任务报酬 |

- 物价锚点：一颗筑基丹市价约三百下品灵石；金丹期修士一年开销约千枚中品——数字前后必须对得上

## 该题材高频吃书点

> 收尾自检时优先核对以下四类前后矛盾：

1. **越级战斗无代价**：主角反复越级获胜且毫发无损——若设定了境界压制，每次越级必须写出依仗（法宝/阵法/地利/同归于尽的决心）与代价；频繁裸胜 = 硬规则形同虚设
2. **复活滥用**：前期「魂飞魄散即永灭」，后期重要角色一个个被拉回来——复活通道开一次口子，死亡就不再有重量；确要写假死，须提前埋「尸身未毁/一缕残魂」的伏笔并编号
3. **境界注水**：配角境界随剧情需要涨落、敌人境界上不封顶——境界一旦报出就记入 tracking，再出场不得悄悄变更
4. **灵石经济崩坏**：前期一块灵石是天价，后期主角随手掷出万枚——灵石收支要能对账；主角暴富须有来源（秘境/战争缴获/经营），不能凭空宽裕
