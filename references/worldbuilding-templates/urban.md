# 世界观骨架 · 都市异能

> 用法：整份拷进书目录 `worldbuilding.md` 后按本书设定改写。示例值可直接用也可替换；末尾两张表是脚本解析的权威格式——表头与列数不可改，触发词用中文顿号「、」分隔。改完删除本行。

## 力量 / 能力体系

- 能力来源：灵气复苏/基因觉醒——全球 0.1% 人口在{某事件}后觉醒异能；觉醒不可逆，能力类型在觉醒瞬间定型，终身不变
- 分级：E → D → C → B → A → S 六级，官方按「单次输出上限」评级；升级靠实战淬炼 + 稀有觉醒材料，无等级不满级跳变
- 上限与代价：每次动用异能消耗精神力，透支则昏迷 24 小时；S 级全力一击即全国通缉级威慑，异能者不得对普通人出手（官方红线）

## 世界硬性法则

- 表里世界分离：异能对普通人是都市传说，官方压制一切公开暴露；新闻可辟谣，绝不可证实
- 能力定型不可换：觉醒什么就是什么，不存在后期「觉醒第二异能」（合体技是配合，不是新能力）
- 普通人不可觉醒：二十岁后仍未觉醒者终身无望，外部手段（药物/辐射）制造的是怪物不是异能者

## 时代与背景

- 时代设定：现代都市，{2024+N}年「灵潮」降临后第七年；城市面貌如常，暗地里多了一整套异能者管理体系
- 关键背景：三年前「{某市}塌陷事件」首次公开暴露异能冲突，官方随后成立管理局，公司—家族—官方三方默契分治

## 该题材高频吃书点

> 收尾自检时优先核对以下四类前后矛盾：

1. **能力无消耗**：主角连续大战一夜精神力照样充沛、小技能无限连发——消耗与透支后果一旦设定就要每次记账；「这次特殊」需要理由且登记
2. **金钱万能**：危机全靠砸钱解决、觉醒材料随买随有——S 级材料应是剧情级资源（有归属、有争夺），不能随钱包厚度掉落；钱要写来源，钱解决不了的要写清为什么
3. **表里世界悄悄穿帮**：前期异能曝光即官方灭口级大事，后期当街斗法无人报道——保密压力是这个世界观的核心张力，每次公开冲突都要写善后（辟谣/目击者处理/记忆抹除）
4. **评级通胀**：中期满街 A 级、后期 S 级扎堆，稀释主角强度——各等级人口比例设定后不得暗中放宽；新强敌出场先对表再写
