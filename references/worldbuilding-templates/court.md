# 世界观骨架 · 宫廷权谋

> 用法：整份拷进书目录 `worldbuilding.md` 后按本书设定改写。示例值可直接用也可替换；末尾两张表是脚本解析的权威格式——表头与列数不可改，触发词用中文顿号「、」分隔。改完删除本行。本书无超自然力量，能力白名单收录的是「可考察的技艺与资源」。

## 权力结构（力量体系）

- 权力来源：皇权授名分，实权靠「人 + 钱 + 信息」三柱——官位是壳，能调动多少人、握多少把柄才是里子
- 等级：皇帝 → 摄政/首辅 → 六部尚书 / 王爷 → 侍郎 → 御史/州府 → 胥吏；后宫平行一套（太后 → 皇后 → 四妃 → 嫔 → 婕妤以下），前朝后宫互为奥援
- 上限与代价：名分不能凭空造——废立、封王、赐死必须走明诏与礼制，绕过程序者天下共击之；每一次越程序的成功都要预支更大的政治债

## 世界硬性法则

- 信息有腿：一切消息靠人传——驿马三日八百里是极限，密谈必须有在场者或耳目才可能外泄；「人人皆知」的事必须交代传播链
- 无超自然：无武功飞檐走壁、无巫蛊真实生效（巫蛊只是构陷罪名）；毒杀、刺杀都受物理与程序约束
- 礼法即武器：嫡庶、孝期、避讳、朝仪不是背景板——程序瑕疵随时可以成为政敌的刀，也随时能救人

## 时代与背景

- 时代设定：架空古典王朝「{大雍}」，类明代中期——内阁成熟、宦官可与士大夫分庭、江南税赋与北境军费是国库死结
- 关键背景：先帝暴毙无遗诏，幼帝登基，太后垂帘与首辅辅政互相提防；三年前「{漕银亏空案}」至今没清算完，是各方旧账的引线

|---|---|---|
| 帝党 | 幼帝亲信与寒门御史 | 主角的依靠，也随时拿主角当刀 |

- 社会形态：官绅一体的小政府——皇权不下县，基层靠胥吏与宗族；信息差是一切权谋的原材料

## 信息传递

| 渠道 | 速度 | 特点 | 典型用途 |
|---|---|---|---|
| 驿传塘报 | 官方，日行三百里 | 全程留档，政敌可查 | 公开政令、军情 |
| 家书 / 私账房 | 慢，数日到数月 | 可夹私货、可被截 | 拉拢、密谋、银钱调度 |
| 内廷耳目 | 快，当日至次日 | 只听上意，按主子站队 | 妃嫔动向、御前失仪 |
| 说书人 / 商队 | 最慢但覆盖广 | 传谣言的正规军 | 造势、毁誉、民间风向 |

- 保密锚点：一桩密谋从发生到「该知道的人都知道」，至少写明两个环节——谁传的、走了哪条渠道；断链即穿帮

## 该题材高频吃书点

> 收尾自检时优先核对以下四类前后矛盾：

1. **凭空知晓密谈**：主角总能「恰好听到」密室对谈、消息总比驿马快——每次获知敏感信息都要能答上「谁说的、走哪条渠道、付出什么代价」；答不上就改成正式场合的只言片语推理
2. **身份隐藏过久无解释**：主角顶着易被识破的秘密（假身份/前朝血脉）横行三卷无人起疑——每卷至少安排一次「险些暴露 + 一次糊弄过去」的具体场面，糊弄手段不得重复
3. **程序随手破**：圣旨说来就来、说废就废——名分变动是这个世界观的重型操作，写之前先确认诏书流程、谁背书、谁反对；绕过程序的成功必须标 `rule_overrides` 并埋政治债
4. **权谋结果无成本**：主角步步算计全中、政敌一倒就再无声息——每次得手要写反噬（言官弹劾/盟友分赃/旧案翻出）；对手败退要有残部与反扑时间表
