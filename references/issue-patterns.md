# 缺陷模式库（issue-patterns）

写作/审稿中发现的新问题模式在此登记，检测脚本同步补正则——技能越用越强。
**发现流程：真人反馈 / 子代理扫描 / 冷读顺带挑 → 登记本文件 → 同步 checks/check_continuity → 回归。**

## 语病定式（checks.py cmd_prose_issues）

| 模式 | 示例 | 正解 | 发现来源 |
|---|---|---|---|
| 数量定语错位 | 亮着三分之一的灯 | 还有三分之一的灯亮着 | 真人反馈 2026-08 |
| 悬空同位语 | 需求文档，第十七版。 | 已经改到第十七版 | 真人反馈 2026-08 |
| 并列数量冲突 | 就剩他一个，和灯 | 只剩他和灯 | 真人反馈 2026-08 |
| 比喻与本体重复 | 亮着一半，像一盏半明半暗的灯 | 换喻体或删 | 扫描 2026-08 |
| 主语淹没 | 通过/随着…使… | 删介词让主语站出来 | CLG-CGEC 调研 |
| 句式杂糅 | 据数据显示/原因是由于/目的是为了 | 各留一个 | CLG-CGEC 调研 |
| 多重否定 | 避免不迟到 | 避免迟到 | CLG-CGEC 调研 |
| 数量表达 | 降低三倍/大约五十人左右 | 降到三分之一/大约五十人 | CLG-CGEC 调研 |
| 关联词错配 | 不仅…但… | 不仅…而且… | CLG-CGEC 调研 |
| 成分赘余 | 凯旋归来/免费赠送/亲眼目睹/十分非常/差不多几乎/彻底根治/多余的赘述/涉及到/诉诸于 | 删赘余部分 | CLG-CGEC 调研 |
| 处所+状态搭配 | 办公区还黑着 / 楼还亮着 | 主语换成灯或天色（办公区的灯还没亮），无灯无光直接写「空无一人」 | 真人反馈 2026-08-15 |

## 待办（尚未脚本化，靠 LLM 维度）

- 语序不当类（编辑距离 11.24，不可正则）：冷读/polish 子代理
- 指代悬空、歧义：polish 子代理（例：「他盯着那行字」前文只有文件名、没有任何一行字→要写「那个文件名」；情绪比喻别用食物充饥意象，「胃里塞了块煎饼」读成吃撑，重量/温度意象才传发沉）
- 逻辑错误、事实矛盾（非数字）：冷读+账本人工核对
- 时间点与自然常识矛盾（「早上7:40 天还黑」类，需季节/纬度常识，正则不可靠）：作者级 playbook「避开」清单已登记，靠写作时核对 + 冷读/polish 子代理顺带挑
- 在场状态矛盾（「办公区只有主角一人」vs「某领导七点已上班」「凌晨三点语音」vs 未加班——角色在场/不在场、通宵与否的多事实交叉）：写「只有主角一人/空无一人」后要建一张当场的「在场表」；催稿者用睡前正常时间（昨晚十一点半）交代不在场，不写凌晨时间点（「半夜醒了却不加班」立不住）
