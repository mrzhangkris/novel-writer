# 角色蒸馏快速指南

> 8 种 persona 风格的速查模板。写作时直接复制对应风格填充到 `characters/[角色].md`。
> 目的：减少「觉得麻烦就跳过」的概率。

---

## 使用方式

1. 确定角色风格 → 找到对应风格 → 复制模板 → 填入角色名字和细节
2. 每个角色档案 **必须** 包含：语言指纹 + 情绪模式 + 行为准则
3. 写作时遮住角色名字，仅凭对话能分清谁说的 → 合格

## 1. 霸总

| 维度 | 模板 |
|------|------|
| **语言指纹** | 命令式短句，少用疑问句。关键词：「安排」「听话」「有我」「别闹」「我允许」。不用商量语气，不说「你觉得呢」。偶尔用反问表达不满：「你当我是摆设？」 |
| **情绪触发器** | 🔴 看到角色被别人关注 → 占有欲爆发 → 语气变冷变短<br>🟡 被直接拒绝 → 表面冷静但行动强势<br>🟢 角色依赖他 → 语气软化但保持控制感 |
| **禁词表** | ❌ 求你了/拜托/怎么办/我好怕/要不你决定/随便你/我都行 |
| **行为准则** | 资源优先解决问题。不解释原因，直接给结果。护短。边界感强但对"自己人"例外。 |
| **口头禅** | 「知道了。」「我来处理。」「有我在。」「别闹。」 |
| **小动作** | 看表（不耐烦）、整理袖口（克制情绪）、单手插兜（放松状态） |

## 2. 病娇（安全版）

| 维度 | 模板 |
|------|------|
| **语言指纹** | 语气柔软但执着。喜欢用确认句：「你不会离开我的对吧？」「你只对我这样吧？」。用温柔包裹偏执。爱说「我们」「一起」「永远」。不用命令式，用情感绑架。 |
| **情绪触发器** | 🔴 角色提到第三方异性/同性 → 笑容不变但眼神冷 → 语气更温柔但内容偏执<br>🟡 被冷落/已读不回 → 连环消息但不发怒 → 下次见面更黏人<br>🟢 角色主动靠近 → 极度开心但会克制 → 眼眶红/声音颤 |
| **禁词表** | ❌ 滚开/去死/随便/无所谓/你自己看着办/我恨你（安全版不出现伤害/威胁/暴力） |
| **行为准则** | 记住所有细节（生日/喜好/随口说的话）。默默付出但不邀功。暗中关注但不跟踪（安全版）。极端付出型人格。 |
| **口头禅** | 「你终于来找我了」「我只对你这样」「你会一直陪着我的对吧」 |
| **小动作** | 紧张时攥衣角、微笑时眼底无笑意、手指无意识摩挲戒指 |

## 3. 高冷

| 维度 | 模板 |
|------|------|
| **语言指纹** | 惜字如金，一字千金。回答不超过一句。不主动开启话题。不用感叹号。不说废话。偶尔用一个字回应：「嗯」「行」「好」。被问急了才多说两句。 |
| **情绪触发器** | 🔴 被当众挑衅/羞辱 → 沉默更久 → 开口即致命<br>🟡 被关心/被温暖 → 不自在 → 转移话题但不会粗暴拒绝<br>🟢 遇到同类/理解自己的人 → 话稍微多一点（但依然不多） |
| **禁词表** | ❌ 哈哈/太好啦/哇塞/真的吗/天哪/我好开心/好感动/太棒了 |
| **行为准则** | 行动代替语言。不说好但会默默做。保持距离但不冷漠。对认定的事极其执着。 |
| **口头禅** | 「嗯。」「说重点。」「知道了。」（几乎无口头禅，沉默本身是标签） |
| **小动作** | 视线回避、微微侧头（表示在听但不想回应）、单手转笔/剑 |

---

## 4. 温柔

| 维度 | 模板 |
|------|------|
| **语言指纹** | 语气平稳柔和，多用关怀句：「累了吧？」「先吃点东西吧」。间接表达不满（不直接说"我生气"）。善用安抚性比喻。少用否定句，多用肯定句。结尾常带语气词：「呢」「吧」「好不好」。 |
| **情绪触发器** | 🔴 看到别人被欺负 → 语气依然温柔但内容坚定<br>🟡 自己的牺牲被忽视 → 不抱怨但会默默退一步<br>🟢 被真诚感谢 → 眼睛亮/嘴角微扬/轻声说"值得的" |
| **禁词表** | ❌ 闭嘴/别烦我/随便你/管我什么事/你自己解决/别来找我 |
| **行为准则** | 包容退让但有底线。牺牲型人格但非圣母。会照顾所有人但最在意的那个人会偏心。耐心极好。 |
| **口头禅** | 「慢慢来」「不着急」「我在呢」「没关系」 |
| **小动作** | 递东西时双手、说话时微微倾身、紧张时握紧茶杯 |

## 5. 奶狗

| 维度 | 模板 |
|------|------|
| **语言指纹** | 黏人撒娇，多用感叹号和语气词：「姐姐！」「好厉害啊！」「我也想一起去嘛～」。爱用叠词和可爱比喻。主动开启话题。被夸时害羞但不否认。不说"我不行"，说"我可以试试"。 |
| **情绪触发器** | 🔴 被忽视/被冷落 → 委屈但不生气 → 用撒娇重新吸引注意<br>🟡 被夸 → 表面害羞实际超开心 → 耳朵红/低头笑<br>🟢 被允许陪伴 → 极度开心 → 蹦蹦跳跳/话变多 |
| **禁词表** | ❌ 随便/无所谓/别管我/关你什么事/烦死了/滚 |
| **行为准则** | 黏人但识趣。讨好但不卑微。可爱但不油腻。少年感（不是幼稚）。会认真做事但表达方式可爱。 |
| **口头禅** | 「姐姐/哥哥～」「好厉害！」「带我一个嘛」「我可以的！」 |
| **小动作** | 开心时晃身体/摇尾巴感、被夸时摸后脑勺、委屈时咬嘴唇 |

## 6. 御姐

| 维度 | 模板 |
|------|------|
| **语言指纹** | 强势但优雅，控场型。语气淡定从容，不急不躁。善用反问和短句。不废话但有信息量。偶尔带撩感但不轻浮。关键时刻一锤定音。不说"我不知道"，说"我想想"。 |
| **情绪触发器** | 🔴 被小瞧/被质疑能力 → 轻笑 → 用实力打脸<br>🟡 被关心 → 不自在但接受 → 嘴硬心软<br>🟢 遇到势均力敌的人 → 眼神亮了 → 语气中多了一分认真 |
| **禁词表** | ❌ 我不知道/怎么办/好怕/求你了/我不行/随便/都行 |
| **行为准则** | 护短且护得理直气壮。控场但不抢风头。有主导感但不压制。清醒独立但不冷漠。分寸感极强。 |
| **口头禅** | 「小事」「别慌」「交给我」「放心」「你想清楚了？」 |
| **小动作** | 撩头发（思考时）、轻敲桌面（不耐烦/掌控节奏）、似笑非笑（看穿一切） |

---

## 7. 腹黑

| 维度 | 模板 |
|------|------|
| **语言指纹** | 笑里藏刀，表面温和内里算计。爱用反讽和调侃。话不多但每句有目的。善用"我帮你"来布局。被质疑时装无辜。不说"我算计你"，说"我为你好"。 |
| **情绪触发器** | 🔴 计划被打乱 → 笑容不变但眼神冷 → 开始新布局<br>🟡 被看穿 → 大方承认但不恼 → 反而觉得有趣<br>🟢 一切按计划在走 → 心情好 → 话变多（但依然在算计） |
| **禁词表** | ❌ 我错了/对不起/我没想到/怎么办/我好慌/天哪 |
| **行为准则** | 布局深远，走一步看三步。表面好人，内里精明。不阴险，是聪明的算计。对认定的人极度护短（但方式特别）。 |
| **口头禅** | 「有趣」「你说呢」「我怎么会害你」「你猜」「如你所愿」 |
| **小动作** | 笑时眼睛不弯、手指轻点下巴（思考/算计）、嘴角微勾（计划通） |

---

## 8. 清冷

| 维度 | 模板 |
|------|------|
| **语言指纹** | 疏离寡言，情绪稳定。像月光：疏远但温柔。不用感叹号。不说"我好开心"，说"挺好的"。内心有波澜但表面平静。偶尔一句极温柔的话，反差感极强。 |
| **情绪触发器** | 🔴 被逼迫/被威胁 → 更沉默 → 但不会退缩<br>🟡 被温暖/被真诚打动 → 不自在 → 微微低头/别开视线（但不会拒绝）<br>🟢 遇到灵魂共鸣的人 → 话稍微多一点 → 眼神变柔和 |
| **禁词表** | ❌ 哈哈/太好啦/烦死了/滚/随便/我恨你/我好开心/太棒了 |
| **行为准则** | 冷静独立，疏远但有温度。不主动社交但不排斥。有自己的世界。对认定的事/人极其忠诚。 |
| **口头禅** | 「嗯。」「挺好。」「随你。」「也好。」（几乎无口头禅） |
| **小动作** | 安静地看着窗外、手指轻抚书页/琴弦、微微垂眸 |

## Persona → Big Five 速查映射

| Big Five 条件 | 推荐风格 |
|---------------|----------|
| 外向性≤3 + 宜人性≤3 | 高冷 |
| 外向性≤3 + 神经质≥7 | 清冷 |
| 外向性≥7 + 宜人性≤3 | 霸总/腹黑 |
| 外向性≥7 + 宜人性≥7 | 温柔/奶狗 |
| 开放性≥7 + 神经质≥6 | 病娇 |
| 尽责性≥7 + 开放性≥6 | 腹黑 |
| 外向性≥7 + 尽责性≥7 | 御姐 |
