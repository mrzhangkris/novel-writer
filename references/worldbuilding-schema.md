# worldbuilding 结构化 schema

世界设定文件 `worldbuilding.md` 分两部分：**自由叙事**（人读）+ **两个结构化表格**（脚本读，用于「离奇判定」校验）。这是半结构化设定（ADR-0003）的权威格式定义。

## 硬规则清单（表格）

标题固定为 `## 硬规则清单`，其后紧跟一张表：

```markdown
## 硬规则清单

| 类型 | 规则 | 触发词 |
|------|------|--------|
| 禁止 | 此世界无魔法，力量来源仅为武道修为 | 魔法、法术、咒语、魔力 |
| 上限 | 修为最高九品，不存在超九品境界 | 十品、超品、飞升、破境 |
| 唯一 | 金手指「系统」仅主角一个，不可复制 | 系统、第二个系统、复制系统 |
```

- **类型**：枚举 `禁止` / `上限` / `唯一`
  - `禁止`：此世界绝对不能出现的事物（如「无魔法」）
  - `上限`：某维度有明确数值/境界上限（如「修为最高九品」）
  - `唯一`：某物只能有一个（如「金手指仅此一个」）
- **规则**：一句话自然语言，说明「是什么约束」
- **触发词**：逗号分隔的关键词，脚本据此粗匹配「正文是否触及该规则」

## 能力白名单（表格）

标题固定为 `## 能力白名单`，其后紧跟一张表：

```markdown
## 能力白名单

| 能力名 | 类型 | 等级 | 归属 |
|--------|------|------|------|
| 内力 | 武道 | 一品到九品 | 武者 |
| 轻功 | 武道 | 无等级 | 武者 |
```

- **能力名**：能力的名称
- **类型**：枚举 `武道` / `魔法` / `科技` / `异能` / `仙术` / `其他`（可扩展）
- **等级**：能力的等级范围（如「一品到九品」「无等级」「三级」）
- **归属**：谁能使用（如「武者」「所有人」「XX 势力」）

## 脚本解析约定

- 脚本定位 `## 硬规则清单` 与 `## 能力白名单` 两个二级标题，各解析其后**第一张** markdown 表格
- **离奇判定**：checks.py draft 扫描正文是否命中「禁止」行的触发词——命中时提示；若本章事务已登记 `rule_overrides`（见 architecture.md）则提示已登记放行
- **规则演进**：剧情要打破硬规则时，**不要回来改表**——在当章事务 `delta.rule_overrides` 登记（理由+代价），账本记入 `tracking/overrides.md`；表本身只在该规则「永久废除/替换」时才更新，并在表中注明「见 overrides.md 第X章」
- 表格外的自由叙事仅供人读，脚本不解析
- 表格列数、表头必须严格一致；触发词用中文逗号 `、` 分隔
