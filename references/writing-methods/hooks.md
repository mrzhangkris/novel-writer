# 钩子技法：章级与段落级钩子设计

> 写章首/章尾钩子，或短篇/段落内微钩子时加载。钩子类型统一见「类型总表」，按决策路由选型，章尾套实战模板，段落级用组合与禁忌约束。

## 钩子类型总表（章尾 / 段落通用）

| # | 类型 | 公式 | 示例 | 适用层级 |
|---|------|------|------|----------|
| 1 | 信息差 ★5 | 读者知道关键信息，角色不知道 | "他笑着接过咖啡，不知道她刚才在里面加了一片安眠药。" | 段落/章尾 |
| 2 | 倒计时 ★4 | 设置明确的时间压力，必须到期兑现 | "离婚冷静期还剩最后三天。三天后，他签不签都无所谓了。" | 段落/章尾 |
| 3 | 反转 ★5 | 读者预期突然被打破，真相偏离预期（身份反转、遗嘱反转皆属此型） | "她打开遗嘱，继承人那一栏空着。下一页压着她母亲的死亡证明。" / "她叫林小月。但档案上写的是：林小月，已故。" | 段落/章尾 |
| 4 | 代价/两难抉择 ★4 | 被迫在两个坏选项中选一个，或暗示主角即将失去珍贵之物 | "签了这份文件，公司保住了，但他得进去。" / "举报了他，我也完了。但我还是按下了发送键。" | 段落/章尾 |
| 5 | 物件钩子 ★5 | 重要但含义未知、或不该出现在此的物件引发全局 | "包裹里是一把钥匙，附了张纸条：'你欠我的。'" / "避孕套日期突然变了，连味道也变成了我以前过敏的芒果味。我笑着点头。" | 段落/章尾 |
| 6 | 暗牌 ★4 | 主角藏了一张牌没打，读者等亮牌 | "婆婆骂了整整十分钟。我一句话没说。手机录音还在跑。" | 段落 |
| 7 | 打脸 ★5 | 角色正在得意，读者知道马上要被打脸 | "【就你？也想跟我争？】她笑得前仰后合。我没说话。只是把那份亲子鉴定报告从包里拿了出来。" | 段落 |
| 8 | 弱者/孩子 ★4 | 引入需要被保护的弱者，激发保护欲 | "女儿躲在门后面，捂着耳朵。她才四岁，什么都不懂。但她知道不该出声。" | 段落 |
| 9 | 灵魂旁观 ★5 | 主角已死，以灵魂视角叙述，全知但无力改变 | "我的魂魄慢慢飘起来，看着妈妈铁青的脸。对不起妈妈，我没能站直。" | 段落 |
| 10 | 假意顺从 ★4 | 主动交出前世拼命保护的东西，对手以为她疯了 | "'你既然想要，就都给你吧。'反正谁拿到这笔巨额遗产谁就大祸临头，正愁保命的方法呢。" | 段落 |
| 11 | 冷发现 ★5 | 发现异常后第一反应保持极度冷静，冷静本身制造悬念 | "钥匙扣上印着'悦安月子中心VIP'。我们明明没有孩子。我笑着点头。当天就去月子中心记下了预约单。" | 段落 |
| 12 | 突然揭示 | 抛出改变全局的信息 | "信上的日期，是他死后第七天。" | 章尾 |
| 13 | 紧急危机 | 下章必须回应的紧迫威胁 | "裂缝在扩大，灵石还差三块。" | 章尾 |
| 14 | 未完成动作 | 动作被新变量打断 | "他刚伸手，手腕忽然被人扣住。'别动。'身后传来一个声音。" | 章尾/段落/章首 |
| 15 | 承诺/威胁 | 有人宣布了行动意图 | "今晚十二点之前，我会告诉所有人你做了什么。" | 章尾 |
| 16 | 离奇消失 | 不可能的消失 | "手铐还在，人没了。整个房间只有一个门，门没开过。" | 章尾 |
| 17 | 隐藏含义 | 表面正常，实际暗藏信息 | "他说：'你和妹妹真像。'可她是独生女。" | 章尾 |
| 18 | 意象钩子 | 反复出现的意象发生变化 | "窗台上那盆枯了一个月的茉莉，突然冒出了花苞。" | 章尾 |
| 19 | 回声钩子 | 章尾句呼应开头，关键细节变了 | 开头："她说她永远不会原谅他。" / 结尾："她说她永远不会原谅他。但她的手，攥得更紧了。" | 章尾 |
| 20 | 留白钩子 | 只展示反应，不揭示发生了什么 | "他看了信。脸色变了。什么也没说，把信叠好放进口袋。" | 章尾 |

### 四类归属与轮换判据（对齐 novel-draft 五问闸门⑤ / writing-rules.json）

四类定义：**危机**=命悬一线或紧迫威胁（2/13/14，15 威胁侧）；**悬念**=信息差未解（1/3/5/6/10/11/12/16/17）；**渴望**=目标差一步（7 打脸，15 承诺侧，及一切「就差一点」式收尾）；**情绪**=关系/氛围张力（4/8/9/18/19/20）。轮换纪律按四类判「不连章同型」，不按 20 式一一细判——连用「紧急危机+倒计时」同为危机类即算连章同型。

### 使用要点

- 信息差不能拖太久，超过 3000 字读者会烦
- 倒计时一旦设定，必须到期兑现，不能烂尾
- 反转必须有铺垫，无铺垫的反转是作弊
- 暗牌不能藏太久，短篇里最多藏 30% 篇幅
- 打脸要干脆利落，一句话打脸比一段话打脸爽
- 代价必须真实，主角最后什么都没失去则代价钩子失效
- 弱者不能只是工具人，要有自己的行动线
- 灵魂视角的限制（只能看不能动）必须严格遵守

## 章级钩子

### 决策路由

**章尾钩子：根据本章情绪选类型**

| 本章情绪/阶段 | 推荐钩子 | 为什么 |
|-------------|---------|-------|
| 悬念/未知 | 突然揭示 / 物件钩子 / 留白 | 激发好奇 |
| 紧迫/危机 | 紧急危机 / 倒计时 / 未完成动作 | 制造焦虑 |
| 反转/真相 | 反转 / 隐藏含义 / 回声 | 颠覆认知 |
| 情感/关系 | 代价/两难抉择 / 承诺威胁 / 情感转折 | 拉扯情绪 |
| 系统文特有 | 系统激活 / 选择型 | 期待金手指 |
| 氛围/日常 | 意象钩子 / 离奇消失 / 信息差 | 暗流涌动 |

**章节阶段与钩子强度**

| 故事阶段 | 推荐类型 | 强度 |
|----------|---------|------|
| 第 1 章 | 系统激活 / 截断 / 危机升级 | 必须强 |
| 2-3 章 | 选择 / 信息差 / 情感转折 | 强 |
| 中期日常 | 对话悬念 / 信息差 / 身份即将揭露 | 中 |
| 高潮前 | 危机升级 / 悬念预知 | 强 |
| 大结局 | 时间跳跃 / 情感转折 | 收束 |

### 章首钩子 7 式

按开篇策略选型：**直接冲击**=即时紧迫感；**制造好奇**=信息差驱动；**对比冲击**=反差吸引。

| # | 名称 | 开篇策略 | 公式 | 示例 |
|---|------|----------|------|------|
| 1 | 悬念对话开局 | 制造好奇 | 直接从意味深长的对话开始 | "你确定要这么做？/ 确定。/ 那你就别后悔。" |
| 2 | 闪前碎片 | 制造好奇 | 先给结果碎片，再回正常叙事 | "后来他才知道，那个电话改变了所有事。但此刻他还一无所知。" |
| 3 | 倒计时开局 | 直接冲击 | 开头就建立紧迫感（总表 #2 的开局变体） | "距离合同到期还有 72 小时。" |
| 4 | 神秘独白 | 制造好奇 | 第一人称诡异内心独白 | "我一直在想，那天如果我没有回头，一切会不会不一样。" |
| 5 | 反差场景 | 对比冲击 | 两个截然不同的场景并列 | "一边是婚礼现场，香槟塔堆得老高。另一边，医院走廊的灯在闪。" |
| 6 | 未完成动作开局 | 直接冲击 | 动作进行中被截断（总表 #14 的开局变体） | "他刚把钥匙插进锁孔，门里传来一声轻响。" |
| 7 | 意象预示 | 对比冲击 | 用环境意象暗示即将发生的事 | "天边烧得通红，像是什么东西在着。她抬头看了一眼，继续走。" |

### 章尾实战模板 10 式

### 一、系统激活型（最低谷 + 金手指登场）
公式：{主角}{最低谷状态}之际。{一个感官描写}。叮！【{系统名}，正式启动。】
> 例：就在他万念俱灰之际，一个冰冷的机械音突然在脑海中响起。叮！【年少轻狂系统，正式启动。】

### 二、悬念预知型（冷淡围观 + 预告反转）
公式：{主角}{冷静/冷漠地}看着{对方的嚣张行为}。{一个短句：继续吧/慢慢来/不着急}。{预告即将发生的反转，不透露细节}。
> 例：我冷眼看着笑得前仰后合的人。笑吧。多笑会儿。过了今天，你们就再也笑不出来了。

### 三、截断型（小动作 + 剧烈反应 + 疑问收章）
公式：{一个小动作}。{剧烈反应}。{震惊/疑问。本章结束，不给答案}。
> 例：仅仅一口！她的瞳孔猛地收缩成针尖状。轰！一股恐怖到难以形容的热流，瞬间在她的腹中炸开！这粥有问题！里面到底放了什么？

### 四、选择型（系统双选项，不揭晓结果）
公式：【选择一：{诱人选项}】奖励：{极其诱人} 代价：{隐含风险} /【选择二：{另一选项}】奖励：{另一种诱人} 代价：{另一种风险}。章节结束，不给出选择结果。

### 五、危机升级型（异动 + 新威胁 + 恐惧反应）
公式：{突然的声响/动作}！{新威胁出现}。{主角的恐惧/紧迫反应}。
> 例："都给老子出来！快点！"哐啷！！！一只沾满泥污的军靴，粗暴地踹开了笼门。

### 六、身份即将揭露型（旁观者发现线索）
公式：{一个旁观者}突然{提出疑问/发现线索}。"{暗示主角真实身份的话}"{其他人不以为意，主角暗暗紧张}。

### 七、情感转折型（态度突变 + 示弱请求）
公式：就在这时，{角色}的{表情/态度}突然{大变}。{一个出人意料的示弱/请求动作}。"{戳中主角软肋的话}"

### 八、信息差型（自嘲 + 意象 + 暗示改变）
公式：{主角的自我怀疑/感慨}。{一个意象/比喻}。{暗示即将改变，但不明说}。
> 例：花有重开日，人无再少年。自己怎么就把日子，过成了这副狗屎样？

### 九、对话悬念型（请求 + 回应 + 意想不到后半句）
公式："{提出请求的前半句}"{对方回应}"{意想不到的后半句，不是读者预期的}"
> 例："我有一个请求。"苏牧缓缓说道。"你说。""离婚之前，我要证明一次自己。"

### 十、时间跳跃型（时间标记 + 出人意料结果）
公式：{精确/模糊的时间标记}。{出人意料的结果}。{暗示过程的一句话}。
> 例：三分三秒后。江亦瑶神色从容地走出房间，整理了一下微乱的衣服。

### 三种速写章末钩子

**收获预告型**（副本/任务尾声）
公式：{当前行动接近完成}。{暗示即将获得的奖励}。{一句话暗示奖励比预期更大}。

**反派逼近型**（铺垫段结尾）
公式：{主角当前状态}。{暗处/远方，反派的某个行动}。{暗示这个行动将影响主角}。

**行动预告型**（装逼/打脸前）
公式：{主角做出一个决定}。{一个准备动作}。{暗示即将发生的行动}。不写结果。

## 段落级钩子

### 钩子组合

**基础组合**

| 组合 | 效果 | 适合题材 |
|------|------|----------|
| 信息差 + 暗牌 | 读者知道主角在憋大招 | 复仇、世情 |
| 倒计时 + 代价 | 时间紧迫 + 选什么都亏 | 悬疑、婚恋 |
| 反转 + 打脸 | 情绪过山车 | 所有爽向短篇 |
| 弱者 + 代价 | 共情拉满 | 追妻、世情、死人文学 |
| 暗牌 + 打脸 | 爽感最强 | 复仇、逆袭 |

**进阶组合**

| 组合 | 效果 |
|------|------|
| 物件钩子 + 冷发现 | 日常悬疑感 + 智商碾压 |
| 灵魂旁观 + 弱者 | 极致悲剧 + 保护欲 |
| 假意顺从 + 暗牌 | 三重信息差 + 爽感蓄力 |
| 阶梯背叛 + 冷发现 | 层层加码 + 全程冷静 |

**组合使用原则**
1. 技巧服务表达，不要为了用技巧而用技巧
2. 构思剧情阶段可同时考虑多种技巧丰富剧情
3. 技巧可杂糅使用，没用就丢弃
4. 不要通过单个技巧推导剧情，技巧是工具不是束缚

### 钩子禁忌

| 禁忌 | 说明 |
|------|------|
| 假悬念 | 威胁不存在或立刻解除，读者被骗一次就不会再信 |
| 机械降神 | 章尾抛出危机，下章开头用巧合解决 |
| 过度留白 | 连续多章不揭示任何信息，读者失去耐心 |
| 低风险钩 | 用无关紧要的事制造悬念 |
| 同类型连用 | 连续 3 章以上用同一类钩子（按四类归属判） |

### 对话情绪五级递增

写矛盾冲突时，对话越不礼貌，情绪越强烈：

| 级别 | 类型 | 强度 |
|------|------|------|
| 1 | 客观陈述事实 | 最弱 |
| 2 | 客观陈述 + 提出建议 | 礼貌但有力 |
| 3 | 主观指责 | 开始有冲突感 |
| 4 | 主观指责 + 强制命令 | 强情绪 |
| 5 | 主观指责 + PUA抬升自己 | 最强 |

最强话术：打着"为你好"的幌子，句句不离关心，但句句都是嫌弃、指责、厌恶。

### 不公平伤害钩子

不公平伤害 = 不公平（主角无辜）+ 伤害（物理+精神）

- 精神上的伤害更能拉动读者情绪——大多数读者受气的时候多
- "不患寡而患不均"：减月例大家都减（公平），但唯独主角药材降了一等（不公平）
- 随便挑一种写到位都能拉起对反派的仇恨

**三种伤害类型**

| 类型 | 动机 | 行为 | 态度 |
|------|------|------|------|
| 利益转移型 | 反派不想自己承担代价 | 掠夺、命令、逼迫主角 | 理所应当、趾高气昂 |
| 损失转嫁型 | 反派将受惩罚嫁祸给主角 | 威逼利诱、做局、逼迫顶罪 | 隐蔽、阴险 |
| 针锋相对型 | 反派所处秩序被主角打破 | 陷害、算计、伤害 | 不留活路 |

**压主角的正确方式**
1. 尽量不压——用"他人否定，主角打脸"替代"主角真受委屈"
2. 否定间接化——当面嘲讽改为内心活动或背后议论
3. 否定理由合情合理——基于现有信息的合理判断
4. 否定人物多元化——不同立场否定方式不同
5. 只在卷高潮时稍微压一下

### 围观者质量层级

震惊效果取决于围观者的数量和质量（对应爽点三要素中的"吃瓜群众"）：

| 层级 | 对象 | 特征 |
|------|------|------|
| 低质量 | 群演、打杂、实习生 | 纯情绪反应，无后续 |
| 中质量 | 懂行的从业者、副手 | 能做专业对比，有态度变化 |
| 高质量 | 导演级别、行业顶层 | 反应伴随信息展露、关系进展、拉起期待 |

**围观者分层扩大原则**

| 维度 | 原则 |
|------|------|
| 角色种类 | 多种角色 > 单种角色，每种产生不同反应 |
| 角色数量 | 多人 > 少人，选择可多人出场的场合 |
| 角色层级 | 多层级 > 单层级，路人/同行/高手/反派每层不同 |
| 关系深度 | 熟人 > 陌生人，熟人震惊远爽于陌生人震惊 |

## 悬念与期待管理

### 爽点核心公式

爽点 = 两个逻辑的冲突点：
- **大众逻辑**：对手不可战胜 → 恐惧/绝望
- **主角逻辑**：正好手痒/轻描淡写
- 落差越大 → 爽点越爽

### 爽点三要素与看点对应

| 角色 | 操作 |
|------|------|
| 吃瓜群众 | 用议论吹高对手逼格 → 震惊反应完成打脸升华 |
| 对手 | 嚣张到让读者恨 → 被打脸时才爽 |
| 主角 | 铺垫时低调 → 释放时干脆 |

看点 = 吊起读者期待；爽点 = 满足期待。一一对应：前面铺垫多少，后面爽点就有多少。

### 装逼打脸节奏

| 阶段 | 公众期（5 章循环） | VIP 期 |
|------|-------------------|--------|
| 人设 | 1 章 | 1-2 章 |
| 铺垫 | 2 章 | 5 章 |
| 打脸 | 1 章 | 1-2 章 |
| 善后 | 1 章 | 1 章 |

**关键**：
- 前置小无敌：打脸前必须把道具/人物/实力准备好，没有则读者担惊受怕，嘲讽变虐主
- 铺垫比打脸重要：铺垫到位后主角站着不说话都能装逼
- 打脸对象层级决定爽感层级：路人甲震惊不叫爽，有分量的人震惊才叫爽
- 章末钩子约 100 字即可显著提升完读率

## 检查清单

### 写前自查（章首/章尾）

- [ ] 章首前 100 字有钩子（不是风景/天气开头）
- [ ] 章尾有让读者想翻下一页的东西
- [ ] 钩子强度与章节阶段匹配（日常章不必强钩子）
- [ ] 连续两章不用同一类钩子（按四类归属判）
- [ ] 钩子约 100 字，点到即止，不拖沓

### 拆文评估

拆文时对每个钩子评估：

1. 钩子类型是什么？
2. 钩子在第几句话/第几个字出现？
3. 钩子强度（1-10）？
4. 钩子是否在合理位置兑现？
5. 铺垫和兑现之间的距离是否合适？
6. 是否有钩子未兑现（烂尾）？
