# 剧情爆破器（精简版）

> 来源：vibe-noveling（wwt87）booming skill 吸收。用途：大纲阶段或修订阶段嫌「剧情太平/不够炸」时，把剧情往更狠、更高冲突方向炸开。只负责炸开，不负责判断「会不会太狠」——用不用由作者定。

## 用法

1. 默认给 **10 套**爆破走向，在力度/代价/气质上拉开差异。
2. **至少 2 套必须真正掀桌**：角色死亡、主角重大挫折、失去身份/地位/盟友/肉身/尊严、异常事件入场、主角被算计落入陷阱。
3. 烈度优先：冲突真升级、代价真肉痛、转折不可回头。允许暴力/血腥/神秘学等元素，但必须服务剧情爆点与角色命运改写，不是装饰。

## 四维正交组合（防方案同向收敛）

每套方案 = 四个维度各取一个的独特组合；任意两套「锚点+力学」不得重复。

| 维度 | 选项 |
|------|------|
| 1 锚点（炸什么） | 策略层 / 认知层 / 承诺层 / 关系层 / 权力层 / 信息层 / 时间层 / 规则层——拆掉它，上面的东西会塌 |
| 2 力学（怎么炸） | 反转 / 链式 / 移位 / 侵蚀 / 坍缩 / 碰撞 / 抽梁 / 越界 / 错位 / 蒸发 |
| 3 尺度（炸多大） | 个人 / 关系 / 阵营 / 地区 / 世界 / 超自然 / 元叙事 |
| 4 不可逆性（能不能回来） | 可逆但代价翻倍 / 部分可逆 / 完全不可逆 |

高级技法（每套最多叠 1 种）：回声爆破 / 双盲碰撞 / 延迟引爆 / 嫁接 / 回旋镖 / 假性止血。

## 结构改写验证（每套输出前必过）

问：「如果这件事发生，故事后续走向会不会跟发生前完全不同？」只是「情绪更激烈但大家照旧走老路」= 不通过，重做。

通过标准（满足任一）：阵营关系变了 / 主角身份或自我认知变了 / 目标顺序变了 / 长期敌人提前现身 / 世界观规则出现例外或被重写 / 主角路线被彻底堵死必须换路。

## 输出格式

10 套方案，每套一句话梗概：发生了什么 + 代价是什么 + 不可回头点在哪里，必须含具体角色名与具体事件。选定后落大纲；还不够狠就基于所选方案做第二轮爆破。

## 上下文不足时

基于已有信息先给 10 套，开头写明关键假设；只有缺核心锚点会导致方案完全失焦才补问 1 个问题。
